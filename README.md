This is where my programming journey started. 🌱 It's a collection of **90+ small C programs** I wrote while learning the fundamentals: variables, conditions, loops, arrays, strings, functions and a bit of problem solving.

Nothing fancy here, just honest practice code, kept as a record of how I learned.

---

## 📂 What's inside

```text
computer_programming_1st_part/
├── Unit/        # Examples and exercises, grouped by unit (e.g. 6_5 = unit 6, no. 5)
├── Works/       # Extra problems I solved on my own (Work_01 ... Work_31)
└── Practices/   # Small practice programs
```

### 🔖 A few highlights

| Folder | What it does |
| ------ | ------------ |
| `Unit/5_8 GCD`, `Unit/5_9 GCD with Division Algorithm` | Two ways to find the GCD |
| `Unit/6_5 Array Revers`, `Unit/6_6 Array Revers without using extra memory` | Reversing an array, then doing it in place |
| `Unit/8_1 Binary Shart` | Binary search |
| `Works/Work_05 Find remainder without using modulo operator` | Remainder without `%` |
| `Works/Work_11 C to F and F to C` | Temperature converter |
| `Works/Work_31` | Move around an 8 × 8 grid with commands, avoiding blocked cells |
| `Practices/Practice_01 GCD and LCD Calculator` | GCD and LCM calculator |
| `Practices/Practice_05 D-B _ B-D` | Decimal ↔ binary converter |
| `Practices/Practice_07 Print Human` | Drawing a little human with characters 🧍 |

## 🚀 Run any program

```bash
cd "Unit/5_8 GCD"
gcc 5_8.c -o gcd
./gcd
```
